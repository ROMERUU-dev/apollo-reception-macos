# Apollo Reception for macOS

Portable desktop foundation for Apollo Reception. The project is currently in the **Linux Foundation Phase**: protocol, TypeScript SDK, receipt rendering, hardware simulation, tests, and security boundaries are developed on Linux before a native macOS shell is created and validated on Apple hardware.

This repository does **not** currently contain a validated macOS application, Xcode project, WKWebView integration, native printing implementation, cash-drawer driver, signing, or notarization setup.
